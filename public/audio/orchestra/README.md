# Orchestra samples

Selected MP3 pitches from FluidR3 GM, by Frank Wen and contributors, rendered for
MIDI.js by Benjamin Gleitzman and contributors.

Source: https://github.com/gleitz/midi-js-soundfonts/tree/gh-pages/FluidR3_GM
License: Creative Commons Attribution 3.0 Unported
https://creativecommons.org/licenses/by/3.0/

The upstream project's license attribution is at:
https://github.com/gleitz/midi-js-soundfonts#soundfonts-available

Changes: only the pitches used in the original teaching studies are retained;
keys are converted to MIDI note numbers and packaged as JSON. MP3 audio is
unchanged. The browser applies note envelopes, mixing and sustain crossfades.

Run `node scripts/source-orchestra-samples.mjs` from the repository root to refresh.
The scores and commentary are original educational illustrations, not excerpts
from recordings or from Sebesky's or Nestico's books.
